# Skill examples

One example per skill. Type `/name` in Claude Code and `$name` in Codex. Everything after the name is plain words, so say what you want.

## Feature workflow

```
/research does Postgres 17 logical replication copy sequences?
/grill my plan to move sessions from cookies to tokens
/to-spec
/architect the rate limiter from the spec
/best-of 3 design the cache key format
/to-tickets
/build rate-limiter
/tdd add retry with backoff to the upload client
```

## Review
