# Productivity

General workflow tools.

## User-invoked

Only when you type them.

- **[bro](./bro/SKILL.md)**: Restate the last message in plain words.
- **[handoff](./handoff/SKILL.md)**: Compact the conversation into `.scratch/handoffs/` for another agent.
- **[show-me-your-work](./show-me-your-work/SKILL.md)**: List the decisions behind the work so far, with evidence.
- **[technical-writing](./technical-writing/SKILL.md)**: Write or review docs, PR descriptions, and commit messages.
- **[why](./why/SKILL.md)**: Answer "why does X work this way" with cited evidence.
- **[wait-what](./wait-what/SKILL.md)**: Re-explain a confusing message with the missing context.

## Model-invoked

When you type them, or when the model reaches for them.

- **[grill](./grill/SKILL.md)**: Interview the user about a plan until it's resolved.
- **[unslop](./unslop/SKILL.md)**: Cut AI tells from prose.
- **[writing-for-agents](./writing-for-agents/SKILL.md)**: Write documents agents read.
