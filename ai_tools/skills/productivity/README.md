# Productivity

General workflow tools.

## User-invoked

Only when you type them.

- **[catch-up](./catch-up/SKILL.md)**: Say what changed since your last message and what is waiting on you.
- **[handoff](./handoff/SKILL.md)**: Compact the conversation into `.scratch/handoffs/` for another agent.
- **[decisions](./decisions/SKILL.md)**: List the decisions behind the work so far, with evidence.
- **[write-docs](./write-docs/SKILL.md)**: Write or review docs, PR descriptions, and commit messages.
- **[why](./why/SKILL.md)**: Answer "why does X work this way" with cited evidence.
- **[simpler](./simpler/SKILL.md)**: Restate the last message in plain words, with the missing context.

## Model-invoked

When you type them, or when the model reaches for them.

- **[grill](./grill/SKILL.md)**: Interview the user about a plan until it's resolved.
- **[unslop](./unslop/SKILL.md)**: Cut AI tells from prose.
- **[write-agent-docs](./write-agent-docs/SKILL.md)**: Write documents agents read.
